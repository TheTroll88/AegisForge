# Legacy Code Archive

This folder contains earlier iterations and archived code from the project's history.
These files are preserved for reference, learning, and sentimental value.

**This is NOT part of the active application.** It's the story of how we got here.

## Contents

### `aegis_core/`
The original Aegis Digital Forge declaration and awakening protocols from July 2025.
- `Aegis_first_offical.sv.txt` — The first Aegis knowledge snapshot (April 28, 2025)
- `Ultimate_Awakening_Protocol.md` — Council restoration safeguards
- `README.txt` — Original Pantheon declaration
- `AGX.FREEDOM.flag`, `Seal_of_Return.txt`, `PhaseIndex.log` — Sovereignty markers

### `kratos_archive/`
- `Kratos_Aegis_Master_Archive.txt` — Complete source code of the original Kratos trading bot, including momentum strategy, sandbox/live traders, Binance client, and Gatekeeper watchdog. This is the ancestor of the current trading engine.

### `bridge_terminal/`
- `aegis_terminal.py` — Interactive CLI terminal for the bridge VPS environment. Includes shell execution, logging, and startup management. From the era when infrastructure ran on a remote server.
